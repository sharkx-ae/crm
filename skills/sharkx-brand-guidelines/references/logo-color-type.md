# Logo, Color & Type — full reference

## Logo files (`assets/logos/`)

See `assets/logos/README.md` for the complete file checklist. Until files are added, describe placement in artifacts and use text lockup **SHARKX** on red `#e70101` band.

## Logo rules

- **Clear space:** exclusion zone per brand book — keep free of text, graphics, and edges.
- **Minimum width/height:** 24px (digital) / 15mm (print).
- **Headlines wordmark:** **SHARKX** · **Body:** SharkX · **URL only:** sharkx.ae
- **Misuse (never):** distort, unapproved colors, shadows/gradients on static lockups, busy backgrounds, redraws, descriptor replacing primary on flagship work.

## Color palette (authoritative)

| Name | HEX | RGB | Primary role |
|---|---|---|---|
| SHARKX Red | `#e70101` | 231, 1, 1 | Primary brand, CTAs, chart 1, title bands |
| SHARKX Black | `#1c0f0f` | 28, 15, 15 | Body emphasis, chart 2, corporate logo |
| Red tint 10% | `#fde6e6` | 253, 230, 230 | KPI highlights, soft fills |
| Black tint 10% | `#e8e7e7` | 232, 231, 231 | Borders, zebra |
| Muted | `#5c5656` | 92, 86, 86 | Captions |
| Page | `#fafafa` | 250, 250, 250 | Deliverable page bg |
| White | `#FFFFFF` | 255, 255, 255 | Cards, logo on red |

## Semantic roles (`assets/tokens.json`)

`text.default` = Black · `text.link` = Red · `brand.primary` = Red · `brand.secondary` = Black · `surface.brandRed` = cover bands.

## Type

- **Sharp Sans** — Bold (H1), Medium (H2), Light/Regular (body/UI).
- **GE Flow** — Arabic supporting copy only.
- **Scale (pt, print/pptx):** Display 40 · H1 28 · H2 20 · H3 14 · Body 11 · Small 9 · Footer 8.
- **Web/app:** Body 14–16px; map pt → px proportionally.

## Gradients

Permitted for **digital/motion icon variants only** — not in Word, Excel, static pptx, or print PDFs.
