# sharkx-brand-guidelines (Claude skill) v2.0

Self-contained skill for **SHARKX** analysts: brand, **data analysis presentation**, HTML dashboards, docx, pptx, xlsx.

## Install

Copy the entire `Sharkx` folder to your skills directory so `SKILL.md` is at the root (e.g. `~/.claude/skills/sharkx-brand-guidelines/`).

Add logo PNGs per `assets/logos/README.md`. Optional: Sharp Sans / GE Flow in `assets/fonts/`.

## v2.0 highlights

- **`SKILL.md`** — data-first layout, mode router, KPI/trust rules
- **`references/data-analysis-mode.md`** — analytics structure, KPI defs, regulated copy
- **Expanded** excel / report / pptx / artifacts / workflow / QA (python examples, Chart.js starter)
- **`artifact-starter.html`** — trust line, KPI deltas, Chart.js trend, actions block
