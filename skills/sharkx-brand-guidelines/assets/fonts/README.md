# SHARKX fonts

Brand book specifies:

- **Sharp Sans** — Light, Medium, Bold (headlines, body, UI)
- **GE Flow** — Regular, Bold (Arabic supporting copy)

These are licensed typefaces. For Claude/Office workflows:

1. Install Sharp Sans and GE Flow on the analyst machine, **or**
2. Place licensed webfont files here and reference via `@font-face` in `brand.css` / artifacts.

**Office fallback:** Segoe UI (Windows) / Helvetica Neue (macOS) when Sharp Sans is unavailable — note in document footer.

**Do not** substitute other families without brand approval.

Suggested filenames if you add files:

- `SharpSans-Bold.otf`, `SharpSans-Medium.otf`, `SharpSans-Book.otf`, `SharpSans-Light.otf`
- `GE-Flow-Regular.otf`, `GE-Flow-Bold.otf`
